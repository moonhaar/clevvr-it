# Clevvr website — GitHub Pages

A lightweight static website for Clevvr.

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `clevvr.github.io` if the GitHub organization/user name allows it, or `clevvr-website`.
2. Upload all files from this folder, keeping the `assets/` directory.
3. In GitHub: **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will provide the public Pages URL.

## Before publishing

- Replace `contact@clevvr.com` in `index.html` with the real Clevvr email address.
- Replace/add real case studies as they become available.
- Add a real Open Graph image later if desired.
- Do not claim official partnerships (Axelor/Odoo/etc.) unless the partnership is actually active.
